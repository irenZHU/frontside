# Frontside · ARTVISION — концепт страницы

Редизайн страницы [frontside.ru/catalog/artvision](https://frontside.ru/catalog/artvision/) в премиальной подаче
и конфигуратор «Примерь на фасад».

## Как посмотреть

```bash
node сервер.mjs
```

Открыть http://localhost:4740 — основная страница (`макеты/artvision.html`).
Авторская версия — http://localhost:4740/artvision-v2.html.

## Состав

- `макеты/` — страница, стили и скрипты (заставка, живой свет, слайдеры, конфигуратор `konfigurator.js`)
- `docs/анализ.md` — аналитика клиента
- `референсы/` — скриншоты сайта клиента и макета Figma
